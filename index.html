Bubble Sort

TIME COMPLEXITY O(n²)

Urutkan ketinggian gunung dari yang terendah ke tertinggi. Tekan “Langkah berikutnya” untuk melihat setiap perbandingan.

void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
            }
        }
    }
}

Lihat contoh kode C++ ＋
int linearSearch(int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == target) {
            return i;
        }
    }
    return -1;
}
